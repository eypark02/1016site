# 사이트 설계도(PRD) — (가칭) 공지 문장 다듬기

작성일: 2026-10-28 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
문자메시지나 공지문 문장을 붙여 넣으면, AI가 정중하게·친근하게·짧고 간결하게 세 가지 말투로 자연스럽게 고쳐 주는 사이트.

## 2. 손님(사용자)
- 누가: 모임·단체(동호회, 교회, 아파트 등)에서 안내 업무를 맡은 담당자
- 어디서 알고 오나: (미정)

## 3. 사용자가 궁금한 것 (쓰기 전에)
1. 내가 쓴 문장을 그냥 붙여 넣기만 하면 되나? (사용법이 쉬운가)
2. 결과를 바로 복사해서 단톡방·문자에 붙일 수 있나?
3. 내가 넣은 문장이 어디 저장되거나 남지는 않나?

## 4. 믿게 할 증거 (실제로 있는 것만)
- 첫 화면의 "고치기 전 → 고친 후" 예시 한 쌍 (실제 사이트로 돌려 본 결과를 넣는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 문장 다듬기
- 누르면: 입력한 문장이 세 가지 말투로 고쳐져 아래에 나란히 나온다

## 6. 페이지 구성 (한 장, 위에서 아래로)
1. 첫 화면 — 한 문장 소개 + 문장 입력 칸 + [문장 다듬기] 버튼
2. 결과 — 정중하게 / 친근하게 / 짧고 간결하게 세 칸, 칸마다 [복사하기] 버튼
3. 사용 예시 — 고치기 전 → 고친 후 한 쌍
4. 안내 — "입력한 문장은 저장하지 않아요" + 이름·전화번호 같은 개인정보는 넣지 말라는 안내
5. 후기 자리 (비워 둠)

## 7. 입력 칸에서 받을 것
- 고칠 문장 하나 (글자 수 제한: 1,000자 정도)
- 문의 폼·개인정보 수집은 이번엔 없음

## 8. 정확해야 하는 사실
- 가격: 사용자는 무료. 운영자도 무료(또는 거의 0원) 범위 안에서만 운영한다
  - Claude API는 영구 무료 요금이 없으므로, 콘솔에서 월 사용 한도(예: 최소 금액)를 걸어 그 이상 나가지 않게 한다
  - 하루 전체 사용 횟수에 제한을 두고, 한도를 넘으면 "오늘은 사용량이 다 찼어요" 안내를 보여 준다
- 저장 여부: 입력한 문장과 결과는 저장하지 않는다
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 고친 문장 기록 저장 (Supabase)
- 의견 보내기 폼·관리자 페이지(/admin)
- 자주 쓰는 공지 틀(모임 일정·회비 안내 같은 예시 문장 모음)

## 10. 첫 화면 한 문장 후보
1. 쓰던 공지, 붙여 넣기만 하세요. 세 가지 말투로 다듬어 드려요.
2. 단톡방에 올리기 전, 문장 한 번 다듬고 가세요.
3. 딱딱한 안내문을 읽기 편한 문장으로.

## 11. 다음에 할 것
- 9번 항목들 (공지 틀 → 기록 저장 → 의견 보내기 순서 추천)
- 사용자가 어디서 알고 오는지 정하기 (단톡방 공유 / 검색 / 지인 소개)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문장 고치기: AI(Claude) — Vercel의 /api 함수에서 Claude API를 부른다. 비용을 고려해 빠르고 저렴한 모델(claude-haiku-5-5)부터 쓴다
- API 키: 화면 코드에 넣지 않는다. 사용자가 Vercel 환경변수(ANTHROPIC_API_KEY)에 직접 넣는다
- 문의 저장: 아니오 (이번엔 없음)
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 '따뜻한' 분위기에 맞게 정하고 입력 칸·결과 세 칸·복사 버튼이 있는 한 장짜리 화면을 만든다
2. /api 함수를 만들어 문장 하나를 받아 세 가지 말투 결과를 돌려주게 한다 (글자 수 제한, 하루 사용 횟수 제한, 오류 안내 포함 — 한 번 부를 때 세 말투를 한꺼번에 받아 요금을 아낀다)
3. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
4. 실제로 문장 하나를 넣어 돌려 보고, 그 결과로 첫 화면 예시(4번)를 채운다
5. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): GitHub·Vercel 로그인, Claude API 결제 등록, ANTHROPIC_API_KEY 입력
